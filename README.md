# 🧠 AI-Powered Product Feedback Analyzer

A beginner AI/ML project that analyzes customer reviews 
using sentiment analysis to help Product Managers 
make data-driven decisions.

## 🎯 Problem
PMs receive thousands of user reviews. 
Reading all manually is impossible.

## 💡 Solution
AI tool that categorizes feedback as 
Positive / Negative / Neutral and shows key themes.

## 🛠️ Tech Stack
- Python, Pandas, TextBlob, Streamlit
